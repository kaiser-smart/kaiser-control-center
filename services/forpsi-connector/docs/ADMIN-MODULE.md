# Administrace SO.ai

Implementace je součástí KCC: `/nastaveni#forpsi-admin`. Používá existující session a oprávnění `settings:manage`.

Aktuální kanonická dokumentace je [FORPSI_CONNECTOR.md](../../../docs/FORPSI_CONNECTOR.md).

Pilot 0.2.3 byl nasazen a serverové přihlášení pilotní schránky ověřeno; podrobnosti a provozní hranice jsou v kanonické dokumentaci výše. UI zatím neimplementuje správu grantů/štítků/pravidel/podpisů ani OAuth autorizaci.

Etapa 1 ručního nastavení přidává čtecí výpis metadat skutečných složek a kolekcí, volbu speciálních složek a serverové ověření jejich existence. Nezpřístupňuje obsah ani nová oprávnění. Cílová specifikace a akceptační podmínky: [FORPSI_SETTINGS_DELIVERY.md](../../../docs/FORPSI_SETTINGS_DELIVERY.md).
