# Administrace SO.ai

Implementace je součástí KCC: `/nastaveni#forpsi-admin`. Používá existující session a oprávnění `settings:manage`.

Aktuální kanonická dokumentace je [FORPSI_CONNECTOR.md](../../../docs/FORPSI_CONNECTOR.md).

Funkční lokálně: vytváření a editace schránek, šifrovaná hesla, speciální složky, test připojení,
pozastavení/zapnutí, čtecí přehled práv, pravidel, štítků, fronty a auditu.

Nenasazeno. UI neimplementuje správu grantů/štítků/pravidel/podpisů ani OAuth autorizaci.
První pilotní účet je `oplustil@kaiserservis.cz`; jeho identita byla ověřena ve webmailu, nikoli serverovým přihlášením.
